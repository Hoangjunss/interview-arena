## Câu hỏi (VI)
Địa chỉ logic (ảo) và địa chỉ vật lý khác nhau ra sao? MMU dịch địa chỉ thế nào?

## Question (EN)
How do logical (virtual) and physical addresses differ? How does the MMU translate them?

## Đáp án chi tiết (VI)
**Địa chỉ logic** (virtual): địa chỉ mà CPU/chương trình sinh ra; mỗi tiến trình thấy một không gian địa chỉ ảo riêng, liền mạch, bắt đầu từ 0.\
**Địa chỉ vật lý** (physical): địa chỉ thật trên thanh RAM.\
\
**MMU** (Memory Management Unit) là phần cứng dịch virtual → physical ở mỗi lần truy cập bộ nhớ:\
- **Paging**: địa chỉ ảo tách thành (page number, offset). MMU tra page table để đổi page number → frame number, rồi ghép với offset ra địa chỉ vật lý. TLB (cache của page table) tăng tốc bước tra này.\
- **Base-and-bound** (đơn giản hơn): physical = virtual + base register, và bound register chặn truy cập ngoài vùng.\
\
**Lợi ích**: cách ly tiến trình (không đọc/ghi lên nhau), relocation linh hoạt, hỗ trợ virtual memory (trang có thể nằm trên đĩa). Nhờ vậy chương trình được viết như thể sở hữu toàn bộ bộ nhớ.

## Detailed Answer (EN)
A **logical (virtual) address** is generated by the CPU/program; each process sees its own contiguous virtual address space starting at 0.\
A **physical address** is a real location in the RAM chips.\
\
The **MMU** (Memory Management Unit) is hardware that translates virtual → physical on every memory access:\
- **Paging**: the virtual address splits into (page number, offset). The MMU looks up the page table to map page number → frame number, then combines it with the offset to form the physical address. The TLB (a page-table cache) speeds up this lookup.\
- **Base-and-bound** (simpler): physical = virtual + base register, and a bound register blocks out-of-range access.\
\
**Benefits**: process isolation (no reading/writing into each other), flexible relocation, and virtual memory support (a page may live on disk). This lets each program be written as if it owns all of memory.
