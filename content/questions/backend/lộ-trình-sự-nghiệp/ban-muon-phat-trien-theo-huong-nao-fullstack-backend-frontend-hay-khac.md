## Câu hỏi (VI)
Bạn muốn phát triển theo hướng nào: Fullstack, Backend, Frontend hay khác?

## Question (EN)
Which direction do you want to develop in: Fullstack, Backend, Frontend, or other?

## Đáp án chi tiết (VI)
**Nhà PV muốn nghe:** bạn có chính kiến về hướng đi và lý do kỹ thuật đằng sau, đồng thời đủ linh hoạt với nhu cầu thực tế.\
\
**Tránh:** \\"gì cũng được\\".\
\
**Trả lời mẫu:** \\"Tôi theo hướng Backend vì thích thiết kế database, tối ưu API và xử lý hệ thống chịu tải. Nhưng tôi vẫn giữ được kỹ năng frontend để hiểu toàn cảnh sản phẩm — điều đó giúp tôi thiết kế API mà phía client thực sự dễ dùng.\\"

## Detailed Answer (EN)
**What they're assessing:** that you have a point of view with technical reasoning, while staying flexible to real needs.\
\
**Avoid:** \\"anything works\\".\
\
**Sample answer:** \\"I'm focusing on Backend because I enjoy database design, API optimization, and handling load. But I keep my frontend skills sharp to see the whole product — it helps me design APIs the client side actually finds easy to use.\\"
