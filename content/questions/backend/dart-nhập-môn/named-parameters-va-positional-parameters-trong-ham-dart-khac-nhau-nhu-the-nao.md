What are named and positional parameters in Dart functions?

## Detailed Answer (EN)
Positional parameters are passed in order. Named parameters use curly braces and are called by name. Named parameters can be optional; combine with the `required` keyword to make them mandatory. Named params improve readability for functions with many arguments.
