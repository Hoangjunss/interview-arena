## Câu hỏi (VI)
Bạn cập nhật kiến thức và học công nghệ mới bằng cách nào?

## Question (EN)
How do you keep up to date and learn new technologies?

## Đáp án chi tiết (VI)
**Nhà PV muốn nghe:** một quy trình học cụ thể, kết hợp lý thuyết và thực hành, chứ không chỉ \\"đọc cho biết\\".\
\
**Tránh:** trả lời chung chung \\"tôi tự học trên mạng\\".\
\
**Trả lời mẫu:** \\"Tôi đọc documentation chính thức trước để nắm nền, rồi build ngay một project nhỏ để áp dụng — ví dụ tôi học Go bằng cách viết một CLI tool. Tôi theo dõi vài engineering blog (Netflix, Uber), dev.to, và học best practice qua việc review code của senior. Việc làm tay là phần quan trọng nhất, vì chỉ đọc thì rất nhanh quên.\\"

## Detailed Answer (EN)
**What they're assessing:** a concrete learning process combining theory and practice, not just \\"reading for awareness\\".\
\
**Avoid:** a generic \\"I self-study online\\".\
\
**Sample answer:** \\"I read the official docs first to get the foundation, then build a small project to apply it — e.g. I learned Go by writing a CLI tool. I follow a few engineering blogs (Netflix, Uber), dev.to, and pick up best practices from senior code reviews. The hands-on part matters most, because reading alone fades fast.\\"
