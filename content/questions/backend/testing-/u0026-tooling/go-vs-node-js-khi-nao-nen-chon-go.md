## Câu hỏi (VI)
Go vs Node.js khi nào nên chọn Go?

## Question (EN)
Go vs Node.js: when should you choose Go?

## Đáp án chi tiết (VI)
Chọn Go khi: CPU-intensive tasks, high concurrency (100K+ connections), microservices, CLI tools, system programming, cần type safety mạnh. Chọn Node.js khi: full-stack JS, rapid prototyping, npm ecosystem, real-time (Socket.io), team quen JS. Go nhanh hơn ~10-50x cho compute, Node.js ecosystem lớn hơn.

## Detailed Answer (EN)
Choose Go when: CPU-intensive workloads, high concurrency (100K+ connections), microservices, CLI tools, systems programming, or when strong type safety is essential. Choose Node.js when: full-stack JavaScript, rapid prototyping, leveraging the npm ecosystem, real-time features (Socket.io), or when the team is already JavaScript-focused. Go is roughly 10-50x faster for compute-heavy tasks; Node.js has a larger ecosystem.
