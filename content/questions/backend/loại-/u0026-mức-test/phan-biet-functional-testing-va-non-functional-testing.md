## Câu hỏi (VI)
Phân biệt Functional testing và Non-functional testing?

## Question (EN)
What is the difference between Functional and Non-functional testing?

## Đáp án chi tiết (VI)
- **Functional testing** — kiểm tra hệ thống **làm gì**: các chức năng có chạy đúng theo yêu cầu không (đăng nhập, tính tiền, tìm kiếm...). Tập trung vào *hành vi và kết quả*.\
- **Non-functional testing** — kiểm tra hệ thống **làm tốt tới đâu**: các thuộc tính chất lượng như **hiệu năng, tải, bảo mật, khả dụng (usability), độ tin cậy, tương thích**. Tập trung vào *\\"nhanh/an toàn/dễ dùng thế nào\\"*.\
\
Ví dụ cùng một tính năng \\"đăng nhập\\": functional hỏi *\\"đúng mật khẩu thì vào được không\\"*, còn non-functional hỏi *\\"1000 người đăng nhập cùng lúc thì mất bao lâu, có bị lộ dữ liệu không\\"*.

## Detailed Answer (EN)
- **Functional testing** — checks **what** the system does: do the features work per the requirements (login, billing, search...)? Focuses on *behavior and results*.\
- **Non-functional testing** — checks **how well** the system does it: quality attributes such as **performance, load, security, usability, reliability, compatibility**. Focuses on *\\"how fast/secure/easy to use\\"*.\
\
For the same \\"login\\" feature: functional asks *\\"does a correct password grant access?\\"*, while non-functional asks *\\"if 1000 users log in at once, how long does it take and is any data exposed?\\"*.
