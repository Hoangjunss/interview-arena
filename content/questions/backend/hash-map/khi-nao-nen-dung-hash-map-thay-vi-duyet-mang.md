## Câu hỏi (VI)
Khi nào nên dùng Hash Map thay vì duyệt mảng?

## Question (EN)
When should you use a Hash Map instead of iterating the array?

## Đáp án chi tiết (VI)
Dùng Hash Map khi cần **tra cứu / đếm / kiểm tra tồn tại** với O(1) trung bình thay vì O(n) của brute force.\
\
**Dấu hiệu:**\
- Đề có \\"tồn tại không\\

## Detailed Answer (EN)
Use a Hash Map when you need **lookup / counting / existence check** in O(1) average instead of O(n).\
\
**Signals:** \\"exists or not\\
