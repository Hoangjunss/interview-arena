## Câu hỏi (VI)
STLC (Software Testing Life Cycle) gồm những pha nào?

## Question (EN)
What are the phases of the STLC (Software Testing Life Cycle)?

## Đáp án chi tiết (VI)
STLC là chuỗi hoạt động test có cấu trúc, thường gồm sáu pha:\
\
1. **Requirement analysis** — phân tích yêu cầu, xác định cái gì testable, làm rõ tiêu chí.\
2. **Test planning** — lập kế hoạch: phạm vi, chiến lược, nguồn lực, lịch, tiêu chí vào/ra.\
3. **Test case design** — viết test case, kịch bản, chuẩn bị dữ liệu test.\
4. **Test environment setup** — dựng môi trường, dữ liệu, công cụ cần thiết.\
5. **Test execution** — chạy test, ghi nhận kết quả, log defect và theo dõi.\
6. **Test closure** — tổng kết: báo cáo, đánh giá tiêu chí hoàn thành, rút kinh nghiệm.\
\
Theo khung của ISTQB, các pha này ánh xạ vào **test planning, monitoring \u0026 control, analysis, design, implementation, execution, completion**. Mỗi pha có đầu vào, hoạt động và sản phẩm rõ ràng.

## Detailed Answer (EN)
The STLC is a structured sequence of testing activities, typically six phases:\
\
1. **Requirement analysis** — analyze requirements, decide what is testable, clarify criteria.\
2. **Test planning** — plan scope, strategy, resources, schedule, entry/exit criteria.\
3. **Test case design** — write test cases, scenarios, and prepare test data.\
4. **Test environment setup** — stand up the environment, data, and tools needed.\
5. **Test execution** — run tests, record results, log defects, and track them.\
6. **Test closure** — wrap up: reporting, evaluating completion criteria, lessons learned.\
\
In the ISTQB framework these map to **test planning, monitoring \u0026 control, analysis, design, implementation, execution, completion**. Each phase has clear inputs, activities, and outputs.
