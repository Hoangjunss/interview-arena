## Câu hỏi (VI)
== và .equals() trong Java khác nhau thế nào?

## Question (EN)
What is the difference between == and .equals() in Java?

## Đáp án chi tiết (VI)
**`==`** so sánh **reference** — hai biến có cùng trỏ về một object không. **`.equals()`** so sánh **nội dung** bên trong. Hình dung: `==` hỏi \\"có phải *cùng một* tờ giấy?\\

## Detailed Answer (EN)
**`==`** compares **reference** — whether two variables point to the same object. **`.equals()`** compares **content** inside. Picture it: `==` asks \\"the *same* sheet of paper?\\
