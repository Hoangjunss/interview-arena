## Câu hỏi (VI)
CLR (Common Language Runtime) là gì?

## Question (EN)
What is the Common Language Runtime (CLR)?

## Đáp án chi tiết (VI)
CLR là bộ máy thực thi quản lý các chương trình .NET sau khi biên dịch thành Intermediate Language (IL). Nó đảm nhiệm garbage collection, quản lý bộ nhớ, type safety, bảo mật và xử lý exception. Tất cả ngôn ngữ .NET đều biên dịch ra IL, sau đó CLR dùng JIT compiler để chuyển thành mã máy lúc chạy, giúp đạt được khả năng cross-platform.

## Detailed Answer (EN)
The CLR is the execution engine managing .NET programs after compilation to Intermediate Language (IL). It handles garbage collection, memory management, type safety, security, and exception handling. All .NET languages compile to IL, then CLR JIT-compiles to native machine code at runtime, enabling cross-platform execution.
