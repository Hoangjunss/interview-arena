## Câu hỏi (VI)
Khác biệt cốt lõi giữa dự án Expo và dự án React Native thuần là gì?

## Đáp án trắc nghiệm
- [x] Expo quản lý phần native thay cho lập trình viên
- [ ] Expo chỉ chạy được trên Android
- [ ] Expo dùng phiên bản React khác với React Native thuần
- [ ] Expo không cho phép dùng thư viện bên thứ ba

## Giải thích (VI)
Expo quản lý phần native: cấu hình được sinh từ tệp cấu hình và có dịch vụ build trên đám mây. Dự án thuần thì thư mục android và ios nằm trong kho mã và mọi thay đổi native do lập trình viên tự làm.

### Giải thích các phương án:
- **Expo quản lý phần native thay cho lập trình viên** (Đúng): Cấu hình native được sinh ra từ tệp cấu hình nên phần lớn thời gian không phải mở dự án Xcode hay Gradle.
- **Expo chỉ chạy được trên Android** (Sai): Nó hỗ trợ đầy đủ cả hai nền tảng và cả web.
- **Expo dùng phiên bản React khác với React Native thuần** (Sai): Cùng React và cùng React Native, chỉ khác lớp công cụ bao quanh.
- **Expo không cho phép dùng thư viện bên thứ ba** (Sai): Thư viện JavaScript dùng bình thường, thư viện native cũng cài được qua plugin cấu hình.
