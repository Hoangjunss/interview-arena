## Câu hỏi (VI)
Native stack navigator khác stack navigator viết bằng JavaScript ở điểm nào?

## Đáp án trắc nghiệm
- [ ] Hỗ trợ deep link còn bản JavaScript thì không
- [ ] Không cần bọc ứng dụng trong container điều hướng
- [ ] Cho phép truyền tham số phức tạp hơn giữa các màn hình

## Giải thích (VI)
Native stack dùng thành phần điều hướng thật của Android và iOS, nên hiệu ứng chuyển màn hình và cử chỉ vuốt về do nền tảng xử lý. Đổi lại, khả năng tuỳ biến hiệu ứng ít hơn so với bản dựng bằng JavaScript.

### Giải thích các phương án:
- **Hỗ trợ deep link còn bản JavaScript thì không** (Sai): Deep link do lớp điều hướng chung xử lý.
- **Không cần bọc ứng dụng trong container điều hướng** (Sai): Container vẫn bắt buộc cho cả hai loại.
- **Cho phép truyền tham số phức tạp hơn giữa các màn hình** (Sai): Cách truyền tham số giống nhau ở cả hai.
- **Dùng điều hướng native nên hiệu ứng đúng chuẩn** (Đúng): Hiệu ứng và cử chỉ do nền tảng đảm nhiệm nên mượt hơn và giống ứng dụng native.
