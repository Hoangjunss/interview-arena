## Đề bài (VI)
Cho một mảng các số nguyên `nums` đã được sắp xếp theo thứ tự tăng dần, và một số nguyên `target`. Hãy tìm kiếm `target` trong mảng `nums`. Nếu `target` tồn tại, trả về chỉ số của nó. Ngược lại, trả về `-1`.

## Problem (EN)
Given an array of integers nums which is sorted in ascending order, and an integer target, write a function to search target in nums. If target exists, then return its index. Otherwise, return -1.
